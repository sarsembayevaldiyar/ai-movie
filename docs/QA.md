## Плавность
`python3 tools/qa_motion.py out/astanahub_universe_1080p60.mp4 60 out/qa_motion`. Для каждой пары соседних кадров считаются:
- средняя абсолютная разность яркости (MAD): скачок камеры или пропуск кадра даёт пик;
- средняя яркость: мерцание даёт высокочастотные колебания.

Результат (`docs/qa/motion.txt`, график `docs/qa/motion.png`): медиана MAD 0,0039, максимум 0,0159. Пиков, фризов и событий мерцания нет.

Траектория камеры — один C²-непрерывный сплайн, склеек нет. Скорости и ускорения проверены `npm run camera-report`.

## Правила кода (детерминизм)
- В `src/` нет `Math.random`, `setTimeout`, `setInterval`, `requestAnimationFrame`, `Date.now`, `performance.now`, CSS-анимаций и переходов (проверено `grep`).
- Все случайные величины идут из seeded PRNG (`mulberry32`): звёзды, пыль, зерно, созвездие. Процедурные текстуры тоже собираются из seeded PRNG.
- Время — только из кадра Remotion: `useFilmTime()` → `frame / fps`. Все тайминги заданы в секундах в `src/timeline.ts`. Сид дизеринга — номер кадра.
- Мир — чистая функция `update(t)`. Кадр не зависит от предыдущих, поэтому рендер можно делить на независимые чанки.

## Известные ограничения
- **4K-версия не отрендерена.** На CPU (SwiftShader, без GPU) 4K стоит ~5,3 с на кадр, это ~8 ч. Код готов: `npm run render:4k`. На машине с видеокартой это минуты.
- **Процедурная фактура улиц Астаны** в нижней точке пролёта — художественная, не данные (DECISIONS п. 22).
- **Облака процедурные** (DECISIONS, `docs/ASSETS.md`).
- **Линии проходят за текстом** (граница, сеть, дуги) в духе фирменного паттерна: тонкие линии под типографикой. Белый текст ярче линий, читаемость проверена на полноразмерных кадрах T1, T2 и T5.
- **Среда рендера перезапускала контейнер.** Поэтому финальный чанк отрендерен частями, а H.264 кодировался по чанкам и склеен без перекодирования (`tools/render_parts.sh`, `tools/encode_parts.sh`). На результат это не влияет: рендер детерминирован, частота кадров ровная (проверено выше).
