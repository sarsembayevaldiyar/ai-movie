# BRAND.md: Astana Hub, выжимка брендбука для видео

Источник: `materials/brandbook/ah_brandbook_2024.pdf` (55 стр., «Astana Hub Brand Identity Guidelines 2024»).
Все HEX извлечены из векторных объектов PDF (PyMuPDF), а не пипеткой со скриншота.
**Брендбук — закон.** Всё, что ниже помечено «решение арт-директора», — это места, где брендбук молчит.

### 1.2 Точная геометрия фирменного градиента («Gradients»)
Из PDF-шейдинга `Sh0` (стр. 1, 8, 27, 55): радиальный градиент, **центр в углу кадра** (на обложке это левый нижний угол).
- Стопы: `0.000` светлый → `0.638` тёмный → `1.000` `#000000`.
- Радиус ≈ 1321 px при кадре 1920×1080 (то есть ≈ 0,69 ширины кадра).
- На макетах пара меняется от носителя к носителю (стр. 23, 25, 44–47). На одном кадре — одна пара.

### 1.3 Фирменные линии («Lines»)
Из паттернов `P0…P13` (стр. 1, 29, 39, 43, 55):
- Тонкие дуги (фрагменты больших эллипсов, «орбиты»), которые пересекают кадр. Толщина ≈ **1,96 px** при 1920×1080.
- Обводка — линейный градиент вдоль линии: `#1d1d1b` (0) → тёмный цвет пары (0,362) → светлый цвет пары (1,0), или в обратном порядке.
- Используемые пары: Sky (`#1c4280`→`#5cb4e2`) — основная, Sunset (`#cf4555`→`#fcb75a`) — акцент.
- Обычно 2–4 линии на кадр, линии пересекаются. Могут проходить над градиентом и за текстом.

### 1.4 Пропорции использования (решение арт-директора на основе макетов)
Брендбук не даёт процентов. По всем макетам (стр. 1, 29–55): **~80% чёрный**, ~15% один градиент, ≤5% белый текст и линии.
Белая тема (`#f2f2f2`) в брендбуке есть, но для имиджевого видео выбрана тёмная (как все обложки и «imagery»).

### 1.5 Цвет в видео
- Рабочее пространство рендера — linear. Фирменные HEX переводятся sRGB → linear при подаче в шейдер. На выходе ACES-подобный тонмаппинг, но **фирменные элементы (текст, логотип, градиенты-подложки) рендерятся вне тонмаппинга** (DOM-слой поверх WebGL), чтобы HEX совпадали 1:1.
- Все HEX лежат только в `src/brand.ts`.

## 2. Шрифты (стр. 17, 19–22, 39)

| Назначение | Гарнитура | Начертание |
|---|---|---|
| Заголовки | **Inter** | Semibold (600) |
| Основной текст | **Inter** | Regular (400) |
| Слоган и названия саббрендов | **Inter** | Medium (500) |
| Региональные хабы (лого) | Gilroy | Semibold. **В видео не используется** |
| Документы MS Office | Arial | в видео не используется |

- Семейство Inter допускается целиком: Thin…Extrabold (стр. 22). Inter — OFL-шрифт, подключается локально (`public/fonts`).
- **Иерархия** (по макетам стр. 1, 29, 39, 42–47): гигантский заголовок строчными или в sentence case («guideline», «thank you», «Artificial intelligence») кеглем до 40% высоты кадра; подзаголовок / лид Inter Regular ~48 px; служебные подписи Inter 12–16 px с разрядкой. Заголовки разделов — ПРОПИСНЫЕ с разрядкой (≈ +5%), например «ФИРМЕННЫЕ ЦВЕТА».
- **Трекинг:** на гигантских заголовках отрицательный: −0,042 em («guideline», `Tc −0.042` в PDF), −0,04 em («brand identity»). Интерлиньяж заголовков ≈ 1,0–1,05 (стр. 29: «Join / the unicorn / game»).
- **Фирменный приём «затухающий заголовок»** (стр. 29, 32, 33, 42, 43, 51): белый заголовок с маской-градиентом по вертикали — непрозрачный сверху, прозрачный снизу (luminosity SMask 1→0 на высоту строки). Точки над «i» остаются сплошными.

## 3. Логотип (стр. 9–16)

- **Знак «Link»:** концентрические кольца, разрезанные горизонтальной щелью. Два элемента: знак и шрифтовое написание «astana hub». Вместе — единый символ, по отдельности — «в зависимости от задачи».
- **Версии:**
  - Основная (цветная, серые кольца) на белом — «в большинстве случаев».
  - Инверсия на чёрном — «в особых случаях при разработке имиджевой продукции… не должна стать доминирующей». Видео — имиджевая продукция, поэтому **в финале используется эта версия** (`materials/brandbook/logos/4.webp`).
  - Ч/б: чёрный на фоне 0–50% Black, белый на фоне 51–100% Black (`2.webp`, `3.webp`).
  - Вертикальная компоновка (`1.webp`, только чёрная).
  - Кольца знака на чёрном (стр. 1, вектор): `#1a1a1a`, `#4d4d4d`, `#808080`, `#cccccc`, белый центр.
- **Охранное поле:** X = высота шрифтового написания; со всех сторон не меньше X. Внутрь не заходят никакие элементы, кроме фоновых изображений, не мешающих прочтению (стр. 11).
- **Слоган-локап** (стр. 17–18): `[логотип] | Join the unicorn game`. Вертикальный разделитель, слоган набран Inter Medium, отступы по X. На чёрном — белая версия (стр. 18).
- **Минимальный размер:** в брендбуке не указан. Решение: ширина горизонтального логотипа в видео не меньше 360 px при 1080p.
- **Расположение на носителях** (стр. 12, 42–47): малый белый логотип в верхнем углу, крупный — в центре на финальных кадрах.

## 4. Графические элементы
Структура айдентики (стр. 28): **Logo + Typography + Colors + Gradients + Lines + Photos.**
- **Базовый паттерн** (стр. 24): концентрические круги со ступенчатой заливкой.
  - Светлый: `#ffffff` → `#f6f6f6` → `#eeeeee` → `#e5e5e5` → `#dedddd` → `#d5d5d5` → `#cccccc` → `#c3c3c3` → `#bababa` → `#b1b1b1`.
  - Тёмный: `#1d1d1b` → `#242422` → `#2b2b2a` → `#333332` → `#383837` → `#3f3f3e` → `#464544` → `#4b4b4a` → `#515150` → `#575756`.
  - Стр. 9 «Про знак»: знак рождается из этих колец. Мотив «пульс колец» — прямая цитата паттерна.
- **Фирменный паттерн** (стр. 25): чёрное поле, угловой градиент одной пары, 2–3 тонкие линии-дуги.
- **Фото** (стр. 26): живые люди, событийка, чистая архитектура. В видео фото не используются: условие задачи — «всё кодом».
- **Сетка:** 6 колонок для 16:9 (стр. 41), 4 колонки для вертикали (стр. 53). Поля ≈ 30–40 px при 1920.

## 5. Tone of voice (стр. 5–7, 17)
- Миссия: «Развитие технологических инноваций для экономического роста Республики Казахстан».
- Ценности: инновации и развитие, командная работа, результативность, лидерство, клиентоориентированность.
- Голос: уверенный, амбициозный, короткий. Английские слоганы-ударники («Join the unicorn game», «Make IT Great Again»), остальное — по-русски, просто и без канцелярита.

## 6. Нельзя (явные запреты и прямые следствия правил)
1. Иные способы воспроизведения логотипа, кроме показанных на стр. 13–16: никаких перекрасок, обводок, теней, свечения на самом логотипе, градиентов внутри логотипа.
2. Перерисовывать, растягивать или искажать логотип. Только оригинальные файлы.
3. Заходить в охранное поле логотипа любыми элементами, кроме фоновых изображений.
4. Использовать цвета и градиенты вне палитры стр. 23. Смешивать пары в одном градиенте.
5. Шрифты, кроме Inter (и Arial для документов, Gilroy только для лого региональных хабов).
6. Делать инверсную версию логотипа доминирующей в стиле бренда: в видео логотип появляется один раз, в финале.
7. (Следствие) Чёрный логотип на тёмном фоне и белый на светлом.
