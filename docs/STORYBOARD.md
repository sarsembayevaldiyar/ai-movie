# STORYBOARD: «Astana Hub как вселенная»

**Формат:** 1920×1080, **60 fps**, 90,0 с = **5400 кадров**; мастер ProRes 422 HQ 1080p (4K — опционально, `npm run render:4k`). Один непрерывный пролёт камеры, склеек нет.
**Драматургия:** тишина → нарастание → пик (тезисы, 69–75 с) → спокойная развязка (логотип) → тишина.
Кадры считаются как `секунды × 60`. В коде тайминги задаются только в секундах (`src/timeline.ts`).

## Общая световая логика
Солнце неподвижно в инерциальной системе, Земля вращается (0,35°/с). Камера описана в системе координат Земли.
- Сцены 1–2: подлёт с ночной стороны, восход Солнца из-за лимба.
- Сцены 3–5: вечерний Казахстан сразу за терминатором: огни городов, сумеречная полоса на западном горизонте, лунная подсветка рельефа.
- Сцена 6: общий план планеты, композиция фирменной обложки брендбука (свечение из левого нижнего угла + две орбиты).
